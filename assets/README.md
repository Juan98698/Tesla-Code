# Recursos visuales

El emblema conserva el rostro detallado y la composición T/perfil/terminal de la referencia aportada por el usuario. La computadora holográfica pertenece a la propuesta visual anterior y se conserva con sus maestros. El rediseño del 9 de noviembre de 2026 utiliza una escena CSS 3D con controles HTML y un laboratorio legible.

Los PNG son maestros generados a partir de esas instrucciones. Las versiones WebP solo cambian la codificación de entrega, sin redibujar ni simplificar el retrato. La marca, la navegación móvil y el favicon usan la misma ilustración. El emblema WebP pesa aproximadamente 182 KiB; la escena nueva no descarga la imagen de la computadora ni un motor gráfico. Los PNG y el WebP anterior quedan disponibles como fuentes recuperables.
