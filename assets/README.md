# Recursos visuales

El emblema conserva el rostro detallado y la composición T/perfil/terminal de la referencia aportada por el usuario. La computadora holográfica tiene una pantalla libre para superponer el laboratorio real y lluvia de código confinada a su interior.

Los PNG son maestros generados a partir de esas instrucciones. Las versiones WebP solo cambian la codificación de entrega, sin redibujar ni simplificar el retrato. La marca, la navegación móvil y el favicon usan la misma ilustración. El navegador descarga aproximadamente 285 KiB entre el emblema y la computadora en formato WebP; los PNG quedan disponibles como maestros.
